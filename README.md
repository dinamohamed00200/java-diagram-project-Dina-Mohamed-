# Employee Management System

**Name:** Dina Mohamed

## Description
A simple Java project that implements a UML class diagram of an employee management system.
It has an abstract class `Employee` and three types of employees:
`CommissionEmployee`, `MonthlyEmployee`, and `HourlyEmployee`.
It also has a `Department` class and a `Gender` enum.

## How to Run
1. Open the project in IntelliJ IDEA.
2. Open the file `src/test/MainTest.java`.
3. Click the green Run button next to the `main` method.
